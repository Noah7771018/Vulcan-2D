# VULCAN-2D 模型可靠性复核与 v0.3 修正

日期：2026-07-14

## 结论

这个模型对当前单个 h-BN 1T1M 器件、当前扫描协议下的 I-V 回线与 53 次
循环统计是靠谱的，可作为组会展示、数据插值和器件级蒙特卡洛模拟工具。
它还不能被称为已经验证的微观物理模型，也不应直接外推温度、脉冲速度、
器件面积或器件间差异。

可信度分层：

- 数据复现：较高。主要均值和 CV 基本一致，但仍是同一数据集上的标定，
  不是独立器件盲测。
- 器件端渐进、局域弱区软击穿表征：中高。它不排除纳米尺度金属通道或缺陷桥；
  具体局域结构仍需同批次 CAFM、XTEM 和元素分析确认。
- `sinh` 场辅助输运律：高，但具体归因为 TAT 的可信度只有中低。
- Weibull、log-normal 与 patch 动力学：适合作为统计降阶假设，不是唯一解释。
- 热反馈、激活能和真实时间动力学：当前数据不可辨识，默认关闭热反馈。

## 数据审计

数据源是 `1T1M写入.xlsx` 与 `1T1M擦除.xlsx`，每个文件 53 个循环。全部
循环均保留参与拟合，没有为了改善结果删除异常循环。

- V_SET = 1.298 V，CV = 25.0%；V_RESET = -1.075 V，CV = 24.1%。
- R_HRS = 2.045e8 ohm，CV = 45.5%；R_LRS = 2.939e5 ohm，CV = 28.4%。
- I_cc = 5.146e-5 A，CV = 1.0%；中位存储窗口约 668。
- V_SET 随循环上升约 8.52 mV/cycle；`ln(R_HRS)` 下降约
  0.01177/cycle；`ln(R_LRS)` 上升约 0.006931/cycle，窗口逐渐收窄。
- SET 循环 4、17、19、21、41、42 是低阈值稳健异常点；RESET 前 3 个
  循环的初始 LRS 也明显偏离主体。53 次样本不足以确认异常来源。
- SET 与 RESET 阈值相关性接近零，写入后的 LRS 与下一次擦除初态 LRS
  也几乎不相关，当前数据不足以建立强的跨扫描隐状态耦合。

## 文献证据与边界

逐式推导、证据等级、核心论文阅读笔记和可直接用于论文的物理解释，见
[VULCAN-2D 理论基础、文献证据与论文写作边界](LITERATURE_THEORY_REVIEW_2026-07-14.md)；
配套引用库见 [vulcan2d_theory.bib](../references/vulcan2d_theory.bib)。
导师建议的 1R/1T1R、二维限域、CAFM、XTEM 与原子迁移证据链，见
[文章证据链路线图](PAPER_EVIDENCE_CHAIN_2026-07-14.md)。
朱凯晨博士论文与 Mario Lanza 团队 h-BN 文献的专项核查、软路径到 CNF/QPC
的两工作区解释和可检验预测，见
[ZHU_LANZA_HBN_PHYSICS_REVIEW_2026-07-15.md](ZHU_LANZA_HBN_PHYSICS_REVIEW_2026-07-15.md)。

1. [Zhu et al., Nature 2023](https://www.nature.com/articles/s41586-023-05973-1)
   是当前器件最直接的依据。论文报告约 6 nm h-BN、1T1M 结构、晶体管限流，
   作者将 HRS/LRS 的渐进非线性转变作为非丝状 switching 的支持证据。结合
   该团队的高限流、量子化电导和温升研究后，更谨慎的解释是：器件处于
   晶体管控制的高阻渐进工作区，但微观上仍可包含局部金属通道或本征缺陷桥；
   提高限流和能量后还可能发展为完整 CNF/QPC。模型采用并联局部区域和串联
   晶体管，与该证据相容。
2. [Ranjan et al., ACS Applied Electronic Materials](https://pubs.acs.org/doi/10.1021/acsaelm.2c01736)
   报告 h-BN 击穿前缺陷逐步生成及分子桥连接，并使用 Weibull 击穿统计。
   它支持渐进缺陷演化和 Weibull 作为统计描述，但不唯一推出本模型方程。
3. [h-BN conductive-AFM study](https://pmc.ncbi.nlm.nih.gov/articles/PMC5809508/)
   观察到局域缺陷聚集、残余缺陷和类似软击穿的恢复行为，为 patch/弱点
   表示提供定性支撑。
4. 老师提供的 [2017 SIM2RRAM](../SIM2RRAM/2017%20SIM2RRAM.pdf) 支持电、热、
   缺陷状态耦合的建模框架；[2013 RESET 模拟](../SIM2RRAM/2013%20%E6%A8%A1%E6%8B%9Freset.pdf)
   支持自洽热 RESET 的方法；[2024 Roldan 综述](../SIM2RRAM/2024%20J.%20Roldan.pdf)
   支持 RRAM 随机性分析与 hopping/TAT 等候选机制的比较。
5. 老师给的 QPC 文献和 SIM2RRAM 的主要实例显式假设导电细丝、量子点接触
   或最窄瓶颈。它们适合做局域通道的对照模型；在没有量子化电导证据前，
   不宜直接作为当前 h-BN 1T1M 的主方程。

因此，当前 `sinh(alpha V_h)` 应表述为“由正反向跳跃详细平衡支持的有效缺陷
辅助、场辅助输运律”。该方程有一般理论支撑，但拟合得到的 `alpha` 对应
2.09--2.38 nm 的粗粒化有效电势降长度，不能解释为单一原子跳距。
室温、有限偏压范围内的单组 I-V 即便拟合优良，也不能唯一排除 hopping、
Poole-Frenkel 或 TAT。老师文献中的热方程同理：有方法支撑，但没有当前
实验约束，不能仅因文献中存在就启用。

## v0.3 修正

1. 将 HRS 随机残差与 LRS 软击穿增益分离。旧式乘法会让 HRS 噪声继续
   放大 LRS 和 I_cc 变化；新式状态插值保证两个极限独立且连续。
2. SET 和 RESET 使用各自从对应分支拟合的 `I_s` 与 `alpha`，补偿极性
   非对称；同时重新标定擦除晶体管负载线，修复 RESET 回线系统性低估。
3. RESET 使用随损伤变化的 `phi_min`，避免损伤在 RESET 中消失、下一次
   SET 又突然出现的不连续。
4. LRS 老化采用 `G_on exp(-c_g D)`，保证长期循环下电导始终为正。
5. 根据 53 次循环同时标定均值、CV 与耐久漂移，不再按单指标依次调参。
6. `Rth` 默认设为 0；保留热模块，等待变温或脉冲数据后再识别。
7. 特征估计器按真实电压峰值切分分支，消除转折点数值求导警告。
8. 将器件固定 patch 结构与循环随机种子分离；界面“重新采样”现在只重抽
   C2C 序列，不再混入没有多器件数据约束的 D2D 变化。

|---|---:|---:|---:|
| V_SET | 1.223 V, 22.6% | 1.300 V, 25.4% | 1.298 V, 25.0% |
| V_RESET | -1.083 V, 12.0% | -1.075 V, 24.5% | -1.075 V, 24.1% |
| R_HRS | 2.092e8, 50.0% | 2.038e8, 44.6% | 2.045e8, 45.5% |
| R_LRS | 2.909e5, 29.8% | 2.934e5, 28.6% | 2.939e5, 28.4% |
| I_cc | 5.271e-5, 2.8% | 5.145e-5, 1.0% | 5.146e-5, 1.0% |

v0.3 数字是固定器件下 12 组独立 53 轮 C2C 序列的统计中位数，不再以
单一 seed 2026 贴合实验。序列均值的 10%-90% 区间为：V_SET
1.222-1.312 V、V_RESET -1.124 至 -1.013 V、R_HRS 1.904e8-2.150e8
ohm、R_LRS 2.885e5-3.051e5 ohm。实验值均落在这些区间内。

代表性 C2C 序列的中位 `log10|I|` RMSE：SET 前程 0.177 -> 0.146
decade，SET 回程 0.125 -> 0.106；RESET 前程 0.442 -> 0.278，RESET
回程 0.432 -> 0.181。四分支合并 RMSE 约从 0.327 降到 0.189
decade，下降约 42%。v0.2 数字来自旧固定种子基线，因此这个百分比主要
用于说明回线修正幅度，不是独立测试集上的泛化增益。

## 仍需补的数据

要把模型从“当前数据的可靠降阶模型”推进到“可外推物理模型”，优先级如下：

1. 多温度 I-V：区分 TAT、hopping、Poole-Frenkel，并识别激活能和热反馈。
2. 多扫描速率与多脉宽：拆开 `Kc = rate x dt`，验证 SET/RESET 时间尺度。
3. 独立晶体管输出曲线及确切栅压：减少 h-BN 与晶体管参数互相补偿。
4. 多器件、不同面积数据：分离 C2C 与 D2D，并区分面积分布式导电和少数
   局域通道控制。
5. 更长耐久性序列：验证当前线性阈值漂移和指数电导退化是否仍成立。
6. 局域表征或内部电压信息：检验 patch 状态和 `V_app` 驱动假设。

在获得这些数据前，组会中建议使用措辞：“模型与当前 53 轮准静态数据
定量一致，并与二维限域的渐进缺陷通道相容；通道由金属离子、本征缺陷桥
或二者共同形成，仍待同批次 CAFM、XTEM、元素分析和变温实验辨识。”
