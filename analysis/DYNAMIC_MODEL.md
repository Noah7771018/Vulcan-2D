# VULCAN-2D 动态物理模型（器件级内核 v0.1）

把 [FINDINGS.md](FINDINGS.md) 里的 6 条经验规律,升级成一个 **SIM²RRAM 架构的耦合
电-热-缺陷动力学模型**。关键区别于此前的"行为模型":开关电压、对数正态电阻、限流稳定
性等统计规律**不是手工抽样,而是从物理方程里自发涌现**。

代码:[vulcan_model.py](vulcan_model.py)（引擎）、[run_vulcan.py](run_vulcan.py)（标定+验证）。

---

> **物理诠释更正(据源论文 Nature 2023):** 该器件是**非灯丝型(non-filamentary)**——
> 开关由 h-BN 的软击穿/缺陷重排主导,不是一条导电细丝。因此下文状态变量 `g` **不应理解为
> 灯丝缝宽**,而是**有效隧穿势垒/缺陷软化程度**(分布式缺陷介导的等效隧穿距离):`g` 小=缺陷
> 通路富集=LRS,`g` 大=势垒恢复=HRS。间隙式隧穿数学仅作降阶代理,其 sinh(αV) 即缺陷的陷阱
> 辅助隧穿。详见 [FINDINGS.md](FINDINGS.md) §3.5。

## 1. 模型结构（对应提案的四个物理模块）

**状态变量**:有效势垒/软化度 `g(t)`（nm,等效隧穿距离）。`g=g_min`=LRS,`g=g_rup`=HRS。

### ① 缺陷重排/软击穿（非灯丝,缺陷动力学）— Stanford–PKU 式间隙动力学
$$\frac{dg}{dt} = -\nu_0\,e^{-E_a/k_BT}\,\sinh(\beta V)$$
- 正压 → sinh>0 → dg/dt<0 → 缝合拢（**SET**）；负压 → 撑开（**RESET**）；V=0 → dg/dt=0（**非易失保持**）。
- 强非线性（Arrhenius×sinh）→ 阈值式开关,使 V_set/V_reset 有明确定义。

### ② 电荷输运 I(V,g)
h-BN 间隙支路（陷阱辅助隧穿,间隙越宽指数衰减;场依赖 sinh 来自 HRS 拟合）
$$I_{hBN}=I_{s0}\,e^{-(g-g_{min})/g_c}\,\sinh(\alpha V)$$
与 1T 晶体管支路 $I_t=I_{sat}(1+\lambda|V|)\tanh(|V|/V_k)$ **串联取瓶颈**
（$1/I=1/I_{hBN}+1/I_t$,即电阻相加）。
→ HRS 由 h-BN 限流,LRS 由晶体管限流,二者自动切换。

### ③ 焦耳热/温度场
$$T = T_0 + R_{th}\,|I V|\quad(\text{钳位}\le T_{max})$$
温度回灌进 ① 的 Arrhenius 项,形成电-热正反馈,使开关变陡（见图 (c):SET 时 T 峰 ~375K）。

### ④ 器件变异性（注入物理量,而非直接抽电压）
| 随机源 | 分布 | 涌现出的规律 |
|---|---|---|
| 迁移激活能 $E_a$（SET/RESET 各自独立抽） | $N(E_{a0},\sigma_{E_a})$ | V_set、V_reset 涨落,且**互相独立** |
| 初始断丝间隙 $g_{init}$ | $N(g_{rup},\sigma_{g0})$ | R_HRS **对数正态**（$R\propto e^{g/g_c}$） |
| 闭合间隙 $g_{on}$（灯丝质量） | $N(g_{min},\sigma_{gon})$ | R_LRS 读出涨落 |
| 限流噪声 | $N(0,1\%)$ | I_cc CV≈1% |

## 3. 验证:统计规律全部涌现

| 特征 | 模型 | 实测 | |

| V_reset | −1.075 V (CV 24.2%) | −1.075 V (CV 24.1%) | ✓✓ |
| R_HRS | 1.95×10⁸ Ω (CV 51%) | 2.05×10⁸ Ω (CV 46%) | ✓ |
| R_LRS | 3.67×10⁵ Ω (CV 21%) | 2.94×10⁵ Ω (CV 28%) | ✓ |
| **I_cc** | 5.11×10⁻⁵ A (**CV 1.1%**) | 5.15×10⁻⁵ A (**CV 1.0%**) | ✓✓✓ |
| 存储窗口 | 475× | ~600× | ✓ |
| σ_ln(R_HRS) | 0.51 | 0.52 | ✓✓ |
| corr(V_set,V_reset) | +0.20 | −0.04 | 均在 n=53 抽样噪声内,≈独立 |

**最值得强调的涌现**:
- **R2（I_cc CV≈1%）**:模型中 LRS 顶点恒由晶体管钳位（h-BN 在高压 sinh 发散）,与缺陷
  随机性解耦 → 自动给出极稳的限流。同一只器件 R_LRS 读出却有 ~28% 涨落,模型指出它**只能
  来自灯丝低场电阻的循环涨落**（$g_{on}$）,不可能来自限流档——这是建模反推出的物理结论。
- **R4（电阻对数正态）**:因 $R\propto e^{g/g_c}$ 而 g 正态,对数正态自动成立（σ_lnR=0.51≈实测 0.52）。
- **R4（V_set⊥V_reset）**:SET/RESET 半回线各自独立抽 $E_a$,相关性自然≈0。

## 4. 局限与下一步

- **物理拓扑**:本器件非灯丝型,应把提案的"灯丝形成/断裂 + QPC(LRS)"模块替换为
  非灯丝软击穿/缺陷重排;当前 `g` 已按"有效势垒"重新诠释,但更彻底的做法是改用面分布的
  缺陷密度/连通度状态(percolation 类),而非单一等效间隙。
- 目前是**准静态**扫描积分（每个电压点一步）,$\nu_0\cdot dt$ 合并标定;要做**变扫速/保持时间**
  预测,需把真实时间轴与 $\nu_0$ 解耦（提案模块③的完整电-热瞬态）。源论文 t_SET=232µs、
  t_RESET=783ns（SET 比 RESET 慢 ~300×）→ 标定时间轴时须保留这种**强不对称**。
- 耐久漂移（R5:V_set +8.5mV/循环、窗口收窄）尚未纳入;可加 $E_a$ 或 $g_{rup}$ 的循环累积项。
- $E_{a0}=1.0$eV、$R_{th}$、$\beta$ 等为合理设定值,**变温 I–V 数据**可将其钉死并验证 Arrhenius。
- 串联瓶颈是降阶近似（电阻相加,未做隐式分压求解）;高精度可改成每点隐式求解 $V=V_{hBN}+V_{tr}$。
